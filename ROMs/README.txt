Apart from the Professional DOS ROM, the ROMS in this folder have come from an original working Disk Demon system
for Commodore 64 & Commodore 1541 drive that was bought in the UK around 1987

It is the User Port version

I don't think an Expansion Port version of Disk Demon was ever released.

I don't think a 1571 version of Disk Demon was ever released.

Some of the documentation does refer to a C128 version but I have not been able to track down the C128 Disk Demon kernal ROM yet

The original Disk Demon C64 ROM was a 'dual rom' comprising the C64 Kernal & the Disk Demon C64 kernal.

An adaptor board was also supplied with a physical switch attached that allowed the User to switch between the two kernals.

This adaptor used a 27128 EPROM and had a simple toggle switch to choose the Kernal
